# OpenQuest JDR

Jeu de rôle libre inspiré d'OpenQuest — règles, fiches de personnage et outils de maître de jeu.

## Structure

```
OpenQuest_jdr/
├── docs/          # Règles et documentation
├── characters/    # Fiches de personnage (exemples)
└── tools/         # Scripts et utilitaires
```

## Démarrage

Projet en cours de construction. Les règles et outils seront ajoutés progressivement.
